# 陪我学一会儿

入口：**顶部“学习” → 学习中心 → 陪我学一会儿**。点击后在当前窗口切换页面，托盘“打开学习中心”也复用主窗口。使用现有模型设置，不需要导入 PDF 或安装本地检索模型。知识小窗保留知识卡生成与浏览。

学习中心集中显示继续上次、未完成目标、疑问跟进与巩固入口，保留简洁标题。学习首页可点击“返回知识小窗”；具体学习页先返回学习首页，也可通过顶部品牌按钮回到知识小窗。重复点击顶部“学习”不会重置正在查看的学习页或输入。

从知识卡进入学习、查看已保存会话、配置模型和回到原卡均在同一窗口完成。离开正在生成的学习页会暂停会话，关闭主窗口也会保存并暂停；恢复继续使用原会话和预算。学习页停留期间暂停鼠标移出自动隐藏，离开后恢复原有设置。应用只创建主窗口，已取消独立学习窗口及其导航命令。

2026-09-21 页面拆分验收：前端 196 项测试、后端 212 项测试通过，11 项需单独启用的后端测试未运行；构建与代码检查通过。浏览器预览验证当前页面切换、重复点击保留输入及 360 × 440 布局，知识卡回跳和原有详细解释展开状态由页面集成测试覆盖。本轮未调用真实模型 API。

## 使用

普通知识卡揭晓答案后，点击 **围绕这张卡学一会儿 → 开始围绕这张卡学习**，可从指定卡片进入。前端只传卡片 ID；后端读取数据库原文，保存标题、正文、可信状态和来源快照，供本次学习与恢复使用。预览不调用模型；已有未结束会话时先恢复原进度，不覆盖它。原卡删除后，已经保存的学习快照仍属于学习历史，可通过“清除陪伴学习记录”删除。练习身份由程序绑定原卡，单纯打开或阅读不会写入作答统计。

1. 输入一个主题，或点击兴趣标签；“随便探索”从首选兴趣开始，没有兴趣时从生活科学开始。
2. 助手先读取相关学习记录、搜索已有普通卡片，再准备一小段内容。没有合适卡片时可以补充一般知识，始终标记为 AI 辅助讲解。
3. 点击“继续 / 没看懂 / 太简单 / 举个例子”。下一步由模型结合反馈选择；“没看懂”必须先补基础或换例子，不能直接跳到测验。
4. 小练习可以跳过。提交后先显示参考解析，由用户点击继续；不会自动替用户提交答案。
5. “稍后继续”保留当前位置；“结束并查看小结”结束本次学习。重启后再次进入，可查看保存的内容并继续。不会在应用启动时自动发起模型请求。
6. “本机学习记录”可以回看最近 20 次会话，并单独清除全部陪伴学习记录（包括学习收获和疑问跟进），保留知识卡、收藏和模型设置。

### 按目标学习

在“陪我学一会儿”输入具体目标，选择 **按目标学习**。例如“分清生成和挥发”。原有“开始学习”和“随便探索”保留。

- Agent 先读取上下文、搜索已有卡片，再拆成 1–3 个子目标，为每个目标说明可验证的表现，并问一个卡点问题。用户可以补充最多 300 字，或选择“先从基础开始”明确跳过；程序不会代填卡点，也不把卡点描述当作成绩。
- Agent 根据卡点、已讲内容和真实反馈选择子目标的讲解顺序。目标计划创建后固定，不能覆盖进度。每个子目标讲解一次；全轮最多一次补讲、一道可跳过的验证题，合计最多五个内容步骤。反馈“还没懂 / 举个例子”或验证答错时，尚有补讲机会就先对同一子目标换例子或补基础；用完机会后保留不确定性，不无限重试。
- “目标进度”区分“已讲解”“你反馈已理解”“已完成验证”。“明白了”和“继续”都不产生练习成绩。验证只覆盖所绑定的一个子目标，按本题 AI 参考答案记录一致或不一致，不能推广为其它目标已掌握；跳过验证只结束本轮，保留待验证状态。
- “稍后继续”保留当前步骤；提前“结束并查看小结”后，可从小结、首页“还没完成的目标”（最近三项）或本机学习记录继续同一目标。恢复沿用原会话 ID、卡点、步骤、反馈、待回答问题和执行检查点，**不重置任何预算**。打开记录或点击恢复不自动请求模型。预算用完后仍可查看记录，下一轮需显式开始新目标。
- Harness 验证计划数量、目标 ID、先讲后验、反馈等待、补讲与验证次数，以及是否满足本轮结束条件；目标状态从持久化讲解和真实提交计算，模型没有写入完成状态或分数的工具。所有内容已处理后在本地结束，不额外调用模型。仍支持原有自由提问和学习收获，使用同一预算。
- 目标是用户主动保存的任务，关闭个性化仍可继续该任务；关闭个性化时不读取其他历史学习记录来推荐内容。清除陪伴学习记录会一并删除目标。旧会话通过新增字段的默认值兼容，不转换为目标模式。

### 学习过程中自由提问

- 当前讲解下方有“我想问……”输入框，可提交最多 300 字的具体疑问。模型可以补概念、对比、举例，或者先问一个澄清问题；原来的“继续 / 没看懂 / 太简单 / 举个例子”仍然保留。
- 每次短学习最多提交 4 个问题，共享原有模型、工具和时间预算。回答单独保存在当前步骤下，不消耗六个讲解步骤，也不自动跳入下一段或练习。当前问题未完成时，先继续回答或结束会话。
- 练习需先提交答案才能追问解析；未提交时保留作答和跳过操作。巩固练习作答后也可追问，回答完成后仍能在本地结束并查看小结。
- 问题先保存在 SQLite，再请求模型。相同请求编号重复提交不会新增问题；网络失败或暂停后可继续回答，已经完成的回答不会重复生成。未成功保存的问题保留在输入框中供重试；未发送的草稿不承诺跨退出保存。
- 追问已有明确问题和对应讲解，执行器先完成必要的本地学习上下文及原卡读取，再只向模型开放回答当前问题的工具，避免反复检索耗尽单步轮数。本地读取同样计入工具预算并保存检查点；回答策略仍由模型选择，自由学习生成新讲解时保留自主检索。
- 提交的问题及本次会话上下文会发送给所选模型。问答与原卡快照随学习记录保存、恢复和清除；提问、阅读回答均不改变作答统计或复习时间。

### 回到原卡与保存收获

- 从卡片开始的学习，在进行中和小结中都提供“回到原卡”。按会话保存的卡片 ID 读取当前卡片，并恢复揭晓答案及进入学习时的详细解释展开状态；旧会话默认收起详细解释。原卡删除后提示原卡不存在，学习快照和问答仍可回看。
- 原卡答案下显示最近 20 次相关学习，点击后按会话 ID 读取记录，不自动调用模型。
- 讲解和已完成的追问回答提供“保存这段讲解 / 保存这段回答”。第一版保存实际原文，不自动生成摘要，也不改写原卡。前端只提交会话和内容 ID，后端验证归属后取原文；重复提交不会产生重复收获。
- “学习收获”在本次学习及关联原卡下展示。“查看原始问答”展开并定位对应讲解或回答；“移出学习收获”只移除保存标记与摘录，原学习内容仍保留。
- 保存、回看和移除都在本地完成，不调用模型、不计练习成绩，不改变复习时间。删除原卡不会删除保存的学习内容；清除陪伴学习记录或清除全部本地数据会同时清除收获。

### 跟进未解决疑问

- 回答后可点击“明白了 / 还没懂”。“明白了”只记录用户对解释的主观反馈，并结束该疑问的跟进，不计为掌握成绩。
- 点击“还没懂”，如果仍在对应步骤且本次问答与执行预算允许，会先保存反馈及下一次回答任务，再请求模型结合此前回答重新解释。模型可以补前置概念、换例子或问一个澄清问题；程序拒绝与此前回答仅空白不同的原样重复文本，但这不等于自动判断解释是否有效。
- 当模型先询问卡在哪里时，点击“补充卡住的地方”，填写后“发送补充”。补充与原问题、之前的解释关联在同一条疑问上；后续“明白了”结束这条疑问的跟进。“改问新问题”则创建独立问题，不混入原疑问。澄清补充本身不推断“还没懂”或“已明白”。
- 重新解释同样占用本次最多 4 个问题与原有执行预算。次数耗尽、已经离开该步骤或本次已结束时，仅保存未解决状态；不会偷偷增加预算或自动创建新学习。
- 开启个性化时，首页最多展示 3 个最近的未解决疑问，保留简洁的问题标题入口。进入预览后显示“上次这个问题还没讲明白，要继续吗？”，并引用具体问题说明推荐依据，例如“你上次对‘生成和挥发有什么区别？’反馈‘还没懂’”。已有未完成学习时先继续或结束它。明确开始后再将该问题、对应内容、此前最多三次回答和三次澄清补充发送给所选模型。
- 新会话继续同一条疑问，保留原卡关联及用户补充的卡点。模型给出新回答后仍等待用户反馈，不自行判定解决。旧回答不能覆盖后续回答的反馈；重复点击不会重复创建回答任务。补充先与会话及疑问指向一起保存，网络失败、暂停和重启沿用原有检查点恢复，失败后不用重新描述卡点。
- 关闭个性化后，首页不显示历史疑问，也不能开始或继续基于历史疑问的新会话；可在本地查看和结束。当前普通学习中的主动反馈仍能记录。清除陪伴学习记录同时清除疑问状态。

### 继续上次与巩固一下

以下为练习复习安排，与疑问反馈、保存收获相互独立。

- 学习中心首页“继续上次”只显示最后讲到的标题；尚无讲解时显示学习目标。点击后按会话 ID 恢复内容，不自动生成新的内容；正在生成的会话只读取状态，避免重复请求。
- “巩固一下”仅使用实际提交过的练习记录。首页显示最多三个最早到期的知识点标题，推荐原因放在进入后的预览；没有记录、尚未到期或关闭个性化时分别说明原因，不制造“遗忘”或“掌握”判断。
- 点击知识点先打开本地预览，点击“开始巩固”后才创建会话并调用模型。会发送这一知识点的原题、真实选择和参考解析，先补讲，再换情境提供一道可跳过的小题。有未结束会话时需先继续或结束它。
- 新练习绑定原知识点的 `concept_key`，即使题目标题改变也更新同一条记录。普通自由学习仍以卡片 ID 或“主题＋规范化标题”识别知识点，尚未做跨主题、跨自由学习会话的语义去重。
- 答错安排约 10 分钟后回顾，连续答对按 1、3、7、14、30、60 天递增；沿用现有复习间隔函数。跳过、单纯阅读、结束和点击“继续”均不更新作答统计或复习日期。
- 关闭个性化后，不展示历史驱动的巩固建议，也不允许继续发送过往练习；可以查看、结束已保存会话。删除陪伴学习记录同时清除这些安排。

首页只读取 SQLite，在回到首页、窗口重新获得焦点和可见时每分钟刷新，不后台调用模型。新增 `study_home`、`study_start_review` 命令，复用同一个学习执行器、预算、取消与事务机制。会话 JSON 的新字段有兼容默认值，不需要重建现有数据库；旧练习开始巩固时必须找到原始已提交作答，缺失则拒绝生成。

约 3 分钟是学习长度提示，不保证网络耗时。每次最多 6 个内容步骤、2 道可选小题。小结中的练习结果只表示是否与该题 AI 参考答案一致，不代表外部事实核验或长期掌握。阅读、收藏、跳过练习都不产生掌握分数。

## 实现边界

- `study.rs`：会话、内容步骤、练习与公开响应；提交前不向前端暴露正确选项和解析。
- `study_store.rs`：SQLite 会话、反馈、复习记录和学习收获。版本 11 建立会话与复习表，版本 12 新增 `study_highlights`；收获独立保存，避免与模型检查点写入互相覆盖。
- `study_doubts.rs`：用户明确反馈、疑问跟进与跨会话恢复；版本 13 新增 `study_doubts`。反馈、后续问题及疑问状态在同一事务提交；修订号避免暂停/结束被迟到响应覆盖。
- `study_agent.rs`：七个工具：读取学习上下文、搜索卡片、读卡片、展示讲解、提供练习、结束学习、回应具体问题。待回答问题由程序控制，模型不能用推进课程或结束工具绕过；回答编号与卡片引用需校验。逐步保存检查点，同一工具效果与检查点一同保存。
- `study_commands.rs`：沿用模型通道、系统凭据、模型请求锁、数据清除互斥。会话固定模型，修改模型后可恢复原设置或结束再开始。
- `StudyHome.tsx`：首页本地进度、到期知识点、无记录与关闭个性化的提示。
- `StudyPanel.tsx`：按步骤展示、轻量反馈、按 ID 恢复、巩固预览、小结及记录；离开执行中的会话会请求暂停。

卡片入口使用 `study_start_card_view`（保存详细解释展开状态，保留旧 `study_start_card` 兼容入口），自由提问使用 `study_ask`（补充澄清时携带可选 `replyToQuestionId`），疑问反馈使用 `study_question_feedback`，跨会话疑问使用 `study_start_doubt`；先保存，再由已有 `study_continue` 执行模型请求。会话 JSON 的新增字段均有兼容默认值；数据库自动迁移到版本 13，不需要重建数据库。澄清补充与历史回答各保留最近三条作为后续上下文，完整会话记录仍可回看。

复用现有 `RunControl` 的模型/工具次数、用量估算和执行时间预算，以及复习间隔计算。每次会话最多 24 次模型请求、36 次工具调用，累计执行时间最多 10 分钟（等待用户不计入），单次网络等待最多 60 秒；上下文也有长度上限。失败可手动重试，所有尝试消耗预算。取消停止本地等待和后续调用，不能撤销供应商已经接受的请求或其费用。

本功能的数据在应用数据库的 `study_sessions`（会话）、`study_memory`（练习复习）、`study_highlights`（保存原文）和 `study_doubts`（疑问跟进）表中，与 PDF 复习及普通卡片的收藏/隐藏状态分开。个性化关闭时，工具不返回兴趣、历史反馈或过往练习；当前会话对话仍是继续学习所需上下文。使用模型时会发送相关主题、卡片及允许使用的学习记录，不发送系统凭据以外的无关本机数据。

当前卡片搜索使用 SQLite 关键词匹配，允许 Agent 换词搜索；没有引入向量模型。小段讲解存于学习会话，不自动批量加入普通卡片库。未把普通卡片的历史“已知/隐藏”记录迁移成掌握度。
