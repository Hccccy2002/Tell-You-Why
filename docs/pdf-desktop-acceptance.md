## 真实桌面操作

通过 Windows computer-use 启动 Release APP，点击 PDF 入口，检查现有教材列表，通过系统文件选择框选入三页扫描样例，并点击开始导入。后台真实执行 OCR，页面显示处理进度。入库后，APP 展示 10 个片段和“部分内容可用”标记，正文可直接阅读。

验收首次发现 Windows 对新建发布目录的文件占用。已将 Python 环境、生成数据和临时目录排除出 Vite 开发文件监视，并为 Windows 的暂时共享冲突增加有界重试。通过 APP 的“继续处理”恢复后发布成功；检查点记录证明三页的识别尝试次数均为 1，恢复过程中没有重新 OCR。

暂停与续跑另以真实的 `pythonw.exe` 后台进程、相同 desktop 协议和本地模型进行集成验证：处理首个页面时请求暂停，当前页保存后停止；续跑复用该页并处理剩余两页。配合前端按钮测试，覆盖界面控制与后台恢复链路。过程报告位于 `tmp/kb-ui-reports/`。

## 使用和边界

启动和操作步骤见 [界面使用说明](pdf-desktop-guide.md)。PDF 仍采用之前验收的内容质量规则；检索结果是相关原文，不是 AI 回答。RAG 问答和根据知识库随机生成学习卡片尚未接入。

当前本机运行环境已准备好。Python 环境和模型尚未打包进其他电脑可直接安装的安装包，分发流程仍需后续实现。此次没有连接外部模型服务，也没有上传 PDF。
