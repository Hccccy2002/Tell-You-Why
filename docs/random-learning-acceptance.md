## 构建与桌面

前端已生产构建。桌面程序应使用 Tauri 的本地资源协议；裸 `cargo build --release` 会保留开发服务器路径，不作为有效桌面验收版本。可使用项目标准 Tauri 构建命令，或：

```powershell
cargo build --offline --release --features tauri/custom-protocol --manifest-path src-tauri/Cargo.toml
```
