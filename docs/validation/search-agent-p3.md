# P3 学习中心联网搜索验证

日期：2026-09-21。结论：P3 开发完成，自动化回归及真实联网集成测试通过。未发布安装包。

## 实现范围

- 学习中心“我想问……”支持自动判断、每次联网及单次“本次联网核查”；使用当前学习会话固定的 DeepSeek / Kimi 整理智谱资料。
- 回答保留在当前学习步骤，不修改练习结果、学习小结中的答题统计或掌握状态。
- 问题反馈“还没懂”及疑问重开保留原问题、澄清信息和此前回答；五分钟内且同一天的资料可用于再次解释，时效问题、显式搜索要求或过期资料重新检索。
- 参考资料沿用标题链接样式，不展示摘要；没有原文链接时保留不可点击标题。历史回答及“保存这段回答”的学习收获均保留来源。
- 搜索设置在问题提交时保存快照，重复提交使用同一请求 ID；暂停、结束、恢复沿用父会话版本检查，拒绝迟到结果覆盖。
- 每个问题最多 2 次搜索 HTTP 尝试、3 次搜索规划及回答模型请求、90 秒主动执行时间；一次学习最多 8 次搜索 HTTP 尝试，同时受父会话及每日预算约束。请求失败或中断仍保留已预留用量。
- 保持 `study-companion-v1`。旧 JSON 缺少搜索字段和新增预算项时可恢复，无需清空数据或迁移提示版本。

自动生成学习讲解、目标规划、PDF 问答和新知识卡的联网扩展仍属于 P5。

## 桌面验证范围与发现

在桌面学习中心新建 DNS 测试会话、勾选联网并提交问题，确认进入规划及资料整理阶段。首次真实回答遇到引用校验失败：原错误信息过于笼统，重试也没有带上具体校验反馈。已补充逐段校验原因和反馈重试机制，并通过上述回归与独立真实测试；未保留首个失败响应，因此无法追溯其具体违规字段。

随后窗口最小化且桌面控制工具的激活受用户输入保护阻止，未完成修复后的整套桌面点击与重启回看。最终验证由前端交互测试、后端数据库恢复测试和真实联网集成组成，不将其记为完整桌面端到端通过。桌面操作创建的 DNS 测试会话保留在本机，未删除用户学习记录。

本阶段复用 P2 的共享搜索核心，未针对 DNS、新闻或天气增加专门答案规则。P4 的大规模质量评测及最终交付验收尚未执行。
