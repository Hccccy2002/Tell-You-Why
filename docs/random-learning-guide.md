# 知识库随机学习

在桌面程序中打开 **PDF → 具体教材 → 随机学习**。

1. 选择整本或章节范围，点击 **随机学已有卡片**。此步骤只读取已存卡片，不调用模型。
2. 点击 **揭晓答案** 阅读答案和解释，通过引用查看生成时版本的教材原页。
3. 选择 **掌握**、**需复习** 或 **学习中**；可立即撤销最近一次状态修改。
4. **跳过，下一张** 不会把卡片标为已学。**上一张** 用于回看，不增加展示次数。
5. 离开页面或重启后，进入随机学习会恢复当前卡片、揭晓状态、章节范围和本轮进度；异常后可点击 **恢复学习进度**。

默认未学习优先、按顶层章节分组均衡抽取，已掌握卡片不再进入默认抽样。支持“只看需复习”和“包含已掌握”。若修改范围或筛选，点击“随机学已有卡片”开始新会话。

近期避重取两个集合的并集：近 7 天的展示记录，以及最近 20 次展示记录。卡片 ID 和主素材都参与过滤；旧卡没有主素材时，使用可验证的引用原文保守过滤。不跨知识库合并记录，切换章节仍保留本库近期记录。

候选耗尽时，可扩大章节范围或主动点击 **开始一轮复习（允许近期内容）**。复习轮次放宽近期限制，但仍不会在同一轮反复出现同一卡片或同源素材。

## 随机生成新卡

1. 展开 **随机生成新卡**，选择已配置并通过测试的模型通道。
2. 点击 **随机选材并预览摘录**。程序本地选择未覆盖的合格教材素材，主原文完整进入证据包；关键词检索补充相关原文，不需要额外加载嵌入模型。
3. 核对摘录和供应商后点击 **发送摘录并生成新卡**。
4. 新卡保存为“未学习”，点击“随机学已有卡片”继续。仅生成成功不增加学习次数。

每次最多两次模型调用：生成和支持性审核。失败任务仍计入现有每日教材任务上限，不自动重试或切换供应商。题目重复时保留原卡及原学习状态。预览 30 分钟后过期，修改资料版本或模型后需重新预览。

关闭应用可能中断正在运行的生成。下次启动会将遗留运行任务标为中断失败并释放素材占用，不自动重新发送；用量可能未知，需要用户核对。

## 状态与数据

展示问题只记录“看过”；首次揭晓才从“未学习”进入“学习中”。普通揭晓不会清除“需复习”或“已掌握”标记。今日学习数量按不同卡片去重；主素材覆盖不等于教材真实掌握百分比。

**重置本知识库学习记录** 会要求确认，清除该库学习状态、事件、近期窗口和会话，保留卡片及教材。原有“清除阅读记录”仍只作用于普通卡片；“清除全部本地数据”也会清除新增学习数据。

当前支持单库、单张生成和素材级避重；批量生成、自动间隔复习和跨段同义知识点识别尚未实现。已有学习卡可离线读取，知识库目录和原文预览仍使用当前项目的本地 Python 组件。
