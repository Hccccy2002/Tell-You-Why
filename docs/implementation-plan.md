## 2. 实施顺序和里程碑

### 里程碑一：可运行的基础版本

1. 初始化 Vite + React + TypeScript 和 Tauri 2 工程。
2. 建立窗口、主题令牌、路由/视图状态、错误边界和基础组件。
3. 加入明确标记为“演示内容，未经人工复核”的本地知识卡。
4. 完成首次引导、兴趣选择、问题揭晓、解释和下一条。
5. 验证离线首屏和键盘操作。

完成标准：无 API Key/无网络可完成核心流程；前端检查与测试通过；Tauri 环境可用时完成桌面启动核验。

### 里程碑二：完整本地体验

1. 建立 SQLite 迁移、内容/交互/偏好/设置仓库。
2. 完成反馈、收藏、历史、筛选和本地权重推荐。
3. 完成托盘、全局快捷键、关闭到托盘和窗口状态恢复。
4. 完成通用/提醒设置、暂停提醒、主题和数据清除。
5. 完成离线和数据库异常降级提示。

完成标准：本地状态重启后保留；历史上限和清除边界正确；桌面行为通过人工冒烟测试。

### 里程碑三：模型接入

1. 定义 `ProviderAdapter` 和内置 Provider Registry。
2. 实现 DeepSeek、Kimi（国内/国际预设）适配器。
3. 实现 Windows Credential Manager 密钥保存、删除与掩码状态。
4. 实现白名单 HTTP、连接测试、错误归一化和脱敏。
5. 实现批量生成、整批 Schema 校验、高风险过滤、缓存和指纹去重。
6. 实现 JSON/CSV 导入、校验和导入报告。

完成标准：两家适配器通过 Mock 自动测试；Key 不进入前端持久化、SQLite、配置文件或日志；模型失败时仍可浏览。

### 里程碑四：质量与交付

1. 补齐前端单元/组件测试、Rust 单元/集成测试和关键流程测试。
2. 扫描仓库、数据库 Schema、日志和错误信息的 Key 泄露风险。
3. 审核 CSP、Tauri capabilities、外链和所有内容渲染。
4. 运行格式检查、静态检查、前端生产构建、Rust 测试、Tauri 安装包构建。
5. 编写 README、交付说明、人工事项清单并更新追踪表。

完成标准：项目能按 README 启动、测试和构建；安装包产出或将缺失的系统构建依赖明确标记为受阻。

## 3. 测试方案

### 前端

- TypeScript 严格模式和 ESLint。
- Vitest + Testing Library：引导校验、卡片状态、反馈、设置和错误边界。
- 核心流程：首次启动 → 选择兴趣 → 揭晓 → 展开 → 反馈 → 下一条。
- 最小窗口、键盘 Tab/Enter/Space/Escape、可见焦点和 ARIA 冒烟检查。

### Rust 核心

- `cargo fmt --check`、`cargo clippy --all-targets --all-features -- -D warnings`。
- SQLite 迁移、CRUD、历史上限、清除范围和推荐权重单元测试。
- Provider Registry、白名单、重定向、错误归一化和响应解析测试。
- 使用本地 Mock Transport 测试 DeepSeek/Kimi，不使用真实 Key、不产生费用。
- JSON/CSV 导入的合法、缺字段、危险主题、重复和整批失败测试。
- SecretStore 使用内存替身测试；Windows 真正凭据只做人工测试。

### 桌面与交付

- 开发启动冒烟：启动后 2 秒内显示本地卡。
- 托盘、关闭到托盘、快捷键冲突、窗口越界恢复、多显示器人工测试。
- 通知、静默时段、暂停提醒和睡眠恢复人工测试。
- `npm run build` 和 `npm run tauri build`；记录 NSIS/MSI 产物。
- 静态扫描常见 Key 前缀、Authorization、敏感日志和宽泛权限。
