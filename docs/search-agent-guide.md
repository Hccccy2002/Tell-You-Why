# 智谱联网追问

目前适用于知识卡的普通追问、划词解释，以及学习中心的“我想问……”和问题反馈“还没懂”后的再次解释。回答仍由已配置的 DeepSeek 或 Kimi 生成。

## 配置

打开 **菜单 → 更多设置 → AI 模型 → 智谱搜索**，保存智谱开放平台 API Key，点击“测试智谱连接”。Key 保存在 Windows 凭据库，应用只显示尾号。测试会发送一次固定公开查询，计入每日尝试次数，并可能产生智谱费用。

在下方选择搜索模式并保存：

- **关闭**：默认值。明确的实时问题会提示开启联网；稳定知识沿用原追问流程。
- **自动判断**：稳定原理直接回答，其余问题按需要规划查询。
- **每次联网**：每次追问都要求检索。

支持 Search-Pro 和 Search-Std。切换引擎后需要重新测试连接。每日尝试上限默认为 50，按电脑本地日期计数；错误和取消前已预留的请求也会计入。

## 使用

在卡片答案下方输入问题。勾选“本次联网核查”可单次开启并重新检索，也适用于随后提交的划词解释，不改变全局模式。查询只向智谱发送提炼后的短搜索词；问题上下文和选中的网页摘要发送给当前回答模型。

运行时显示查询进度，可以点击“取消本次查询”。取消后保留草稿、恢复导航，迟到的回答不会写入历史。已经发出的请求可能仍由供应商计费，取消不能撤销计费。

点击回答中的 `[W1]` 等编号展开资料，参考资料只显示标题；有链接的标题在默认浏览器中打开原文。来源元数据与回答一起保存，重新打开卡片或重启后仍可查看标题和引用。历史来源快照不会随五分钟缓存过期而丢失。

智谱有时只返回标题和摘要，原文链接或发布方为空。此类摘要仍会交给回答模型并保留引用，来源区显示不可点击的标题，悬停提示“原文链接不可用”，不补造原文链接。若设置了来源域名范围，无链接资料无法确认属于该域名，因此不纳入该次结果。

## 学习中心

在一段讲解下方的“我想问……”输入问题。默认沿用全局搜索模式，也可勾选“本次联网核查”单次开启。运行中显示规划、搜索、整理进度；可点击“稍后继续”暂停，或结束本次学习。回答后仍停留在原步骤，不改动练习结果和掌握状态。

对联网回答点击“还没懂”会保留原问题和此前解释，换一种方式回答。五分钟内、当天的资料可以复用；问题明确涉及当前信息、明确要求搜索或资料已过期时重新检索。补充澄清问题时仍保留原问题关联。点击“保存这段回答”后，学习收获同时保留引用和可打开的资料标题。

搜索配置在提问时保存快照，暂停恢复不会偷偷更换模式。每个问题最多 2 次 HTTP 搜索尝试、3 次搜索规划及整理模型调用，主动执行时间最多 90 秒；每次学习最多 8 次搜索 HTTP 尝试，同时受原学习会话的模型、工具、Token、主动耗时及每日搜索上限约束。失败、暂停和重启不会清零已预留用量。暂停或结束后，迟到结果不能覆盖会话；恢复时仍有效的已完成检索可直接用于回答。

旧会话兼容原 `study-companion-v1` 提示版本，无需清空学习记录。旧数据缺少搜索字段时正常加载；首次继续尚未准备工具动作的问题时读取搜索设置，已保存的旧工具动作按原流程完成。

## 范围与限制

- 每次搜索运行最多 2 次搜索 HTTP 尝试，联网规划与回答合计最多 3 次模型调用；搜索阶段最多 20 秒，整个运行最多 90 秒。模型回退复用已检索的资料。
- 当前实现仅对临时不可用故障做一次受限重试；无结果不会自动放宽日期要求，也不会无限换词补搜。
- 时效问题仍向智谱传递时间范围，但不再仅因网页发布日期缺失或较旧而删除结果。有效摘要及供应商提供的标题、链接等元数据会交给回答模型，结合正文中的事件日期、更新时间或信息有效期整合答案；统一核对主题、对象、地点和目标日期，不能仅凭“今天”等相对时间词推断事实发生时间。
- 若接口确实返回空列表或无有效数据状态，界面显示“搜索提示”，不署名为 DeepSeek / Kimi 的模型回答。如果返回了结果但没有摘要、或全部不符合指定来源范围，会报告返回数量和具体原因。有资料但只能支持部分结论时，保留来源并说明缺口，不从模型记忆补造实时事实。
- 搜索摘要可能不准确，引用通过结构校验不代表结论已获人工核实。当前阶段未完成大规模时效准确率或延迟评测。
- 清除历史浏览记录不会删除卡片追问；删除对应卡片或清除全部数据会删除关联追问与来源。仅删除智谱 Key 会关闭搜索并清除短期缓存，保留已有回答。
- 当前未接入自动生成学习讲解、目标规划、PDF 教材问答、自动生成知识卡；这些属于 P5 扩展入口。未发布新安装包。
