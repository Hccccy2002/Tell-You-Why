# 复习 Agent 分阶段开发记录

本次按“复习场景 → 质量评测 → 执行追踪”顺序开发；每个阶段通过测试后再进入下一阶段。

| 阶段        | 交付内容                                                                  | 当阶段验证                                                     |
| ----------- | ------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 1. 复习场景 | 五个真实工具、模型决策循环、用户答题、SQLite 检查点、暂停与恢复、复习页面 | 前端 108 项、Rust 114 项通过；类型检查、静态检查、生产构建通过 |
| 2. 质量评测 | 十个受控场景、离线运行器、评分脚本、人工标注及报告、可选真实模型运行入口  | 十场景流程通过；评分脚本 6 项测试通过；Ruff、Clippy 通过       |
| 3. 执行追踪 | 持久化事件、耗时及 token 统计、失败和恢复记录、历史与本地 JSON 导出       | 完整回归与界面检查结果见下文                                   |

最终回归：前端 110 项、Rust 115 项、Python RAG 59 项、评测评分脚本 6 项测试通过；十个模拟场景重新执行通过。Rust 常规测试中的五个忽略项包括已有实机/真实模型测试及新增两个显式评测入口，模拟评测已单独执行。

ESLint、TypeScript、Vite 生产构建、Clippy 均通过。浏览器在 360 × 440 小窗口下验证了选项提交、错题反馈、原文和追踪展开，并修正了全局输入框高度导致的单选框错位；页面无横向溢出。界面检查使用本地模拟 IPC 数据，与真实组件及样式一起运行；桌面文件对话框、凭据库及真实供应商请求不由浏览器模拟验收替代。真实模型内容正确率尚未测量，报告保留未评审状态。

代码修改集中在新增 `review_*` 模块、复习页面、PDF 标签页入口、数据库迁移与评测文件。此前随机学习界面的修改继续保留，并通过原有回归测试。

Windows Release 可执行程序已重新编译通过，根目录的 `启动 Tell You Why.cmd` 会启动更新后的 `src-tauri/target/release/tell-you-why.exe`。本次未重新生成 NSIS/MSI 安装包。
