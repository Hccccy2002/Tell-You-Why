# Windows P0 人工测试清单

## 首次使用与离线

- [ ] 断网启动，2 秒内看到欢迎页中的第一道本地问题。
- [ ] 不输入 API Key，完成至少 3 个兴趣、揭晓、解释、反馈和下一条。
- [ ] 360 × 440 下所有内容可滚动，焦点不被遮挡。
- [ ] 键盘 Tab、Shift+Tab、Enter、Space、Escape 可完成主要操作。
- [ ] 主页面“上一条”可回到前一张，“下一条”可回到刚才离开的后一张。
- [ ] 主页面“不感兴趣”会立即隐藏当前卡并显示下一张；收藏按钮仍可正常切换。
- [ ] 不感兴趣的卡不会被上一条/下一条再次推荐，但仍出现在“收藏与历史 → 最近浏览”。
- [ ] 揭晓后不显示旧反馈组，“返回”恢复当前卡主页面。
- [ ] 点击“已狠狠涨知识”立即进入下一张主卡，原卡仅保留在最近浏览。
- [ ] 未配置模型时点击“再次生成同领域知识点”，提示“请先配置模型哦~”并在 1 秒后消失。
- [ ] 所有主卡移出后出现领域下拉框；兴趣领域优先，并可输入自定义领域。
- [ ] 空状态未配置模型时点击生成，提示“请先配置模型哦~”并在 1 秒后消失。
- [ ] 主卡和内容耗尽页都提供随机领域生成；未配置模型时显示相同的 1 秒温馨提示。

## 持久化

- [ ] 收藏、历史、兴趣、主题和通用设置在重启后保留。
- [ ] 在兴趣设置拖动列表把手后保存并重启，顺序保持；越靠上的已选兴趣显示越高的生成权重。
- [ ] 历史最多 500 条。
- [ ] 最近浏览每条都有删除按钮，删除后收藏、历史和主界面都不再出现该卡。
- [ ] 清除历史后收藏仍存在。
- [ ] 内容有误后卡片立即隐藏，重启后不再出现。

## 窗口、托盘与快捷键

- [ ] 关闭主窗口后进程留在托盘，第一次明确提示。
- [ ] 托盘左键显示/隐藏；菜单的下一条、暂停、设置和退出有效。
- [ ] 默认 Alt + Shift + Y 显示/隐藏。
- [ ] 快捷键冲突时保存失败并显示中文提示，旧快捷键仍可用。
- [ ] 置顶默认关闭，开启后重启保留。
- [ ] 窗口位置、尺寸和显示器重启后恢复。
- [ ] 拔掉外接显示器后窗口回到当前可见屏幕。

## 提醒

- [ ] 默认仅手动打开，不自动请求通知。
- [ ] 工作日 1 次/2 次按设定时间提醒，不播放声音、不展开窗口。
- [ ] 静默时段、暂停 30 分钟和今天暂停有效。
- [ ] 其他应用全屏时不提醒。
- [ ] 同一分钟的提醒不重复。

## 模型与安全

- [ ] 在通用设置把每日生成总数改为自定义数值（例如 37）并保存；下方立即显示“已生成数/37”，重启后数值保留。
- [ ] 成功生成知识点后重新进入通用设置，“已生成数/总数”的已生成数增加；格式错误、请求失败或重复内容不增加该数字。
- [ ] 将总数调低到不大于今天已生成数后，继续生成会提示达到今天上限，本地知识点仍可浏览。
- [ ] 聚焦“每日生成总数”数字框后滚动鼠标滚轮，数值不发生变化。
- [ ] 使用独立低额度测试账户在设置页输入真实 Key；不要记录或截图完整 Key。
- [ ] 保存后输入框清空，只显示最后四位。
- [ ] 连接测试通过后，随机领域、同领域和指定领域生成可用；不操作时不会后台自动生成。
- [ ] 无效 Key、余额不足、429、超时分别显示可执行中文提示。
- [ ] DeepSeek/Kimi 各生成一批，全部标记“AI 生成 · 未经外部核验”。
- [ ] 删除配置后 Windows Credential Manager 中对应项消失。
- [ ] 抓包确认请求只访问官方白名单且没有跨域重定向。
