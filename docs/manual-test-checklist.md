# Windows P0 人工测试清单

## 首次使用与离线

- [ ] 断网启动，2 秒内看到欢迎页中的第一道本地问题。
- [ ] 不输入 API Key，完成至少 3 个兴趣、揭晓、解释、反馈和下一条。
- [ ] 360 × 440 下所有内容可滚动，焦点不被遮挡。
- [ ] 键盘 Tab、Shift+Tab、Enter、Space、Escape 可完成主要操作。
- [ ] 主页面“上一条”可回到前一张，“下一条”可回到刚才离开的后一张。
- [ ] 主页面点击“不感兴趣”先出现影响确认；取消后当前卡不变，确认后隐藏当前卡并显示下一张。
- [ ] 不感兴趣的卡不会被上一条/下一条再次推荐，但仍出现在“收藏与历史 → 最近浏览”。
- [ ] 揭晓后不显示旧反馈组，“返回”恢复当前卡主页面。
- [ ] 点击“已狠狠涨知识”先出现影响确认；取消后不改变收藏/推荐状态，确认后进入下一张，原卡仅保留在最近浏览。
- [ ] 未配置模型时点击“再次生成同领域知识点”，提示“请先配置模型哦~”并在 1 秒后消失。
- [ ] 所有主卡移出后出现领域下拉框；兴趣领域优先，并可输入自定义领域。
- [ ] 空状态未配置模型时点击生成，提示“请先配置模型哦~”并在 1 秒后消失。
- [ ] 主卡和内容耗尽页都提供随机领域生成；未配置模型时显示相同的 1 秒温馨提示。

## 选词查询与追问

- [ ] 揭晓答案后，选择简短答案、详细解释或“为什么值得知道”中的文字，选区右上方出现“让 AI 解释这段？”确认框；未确认前不产生模型请求。
- [ ] 确认框显示选中文字摘录、发送范围和费用提示；点击“取消”、外部区域、滚动、调整窗口或按 Escape 只关闭确认框，不返回主界面。
- [ ] 点击“AI 解释”后，下方追问线程立即显示所选内容和等待状态，最终回答包含实际模型及“AI 未核验”信息；手动追问框中的未发送草稿保持不变。等待期间知识卡、顶栏和桌面快捷导航不可离开，菜单仍能打开并用 Escape 关闭。
- [ ] 选择超过 200 字、跨正文段落、来源按钮或已有 AI 回答时不会发起查询；超过 200 字会明确提示缩短选区。
- [ ] 查询失败后保留“重试选中内容（可能产生费用）”，只有再次点击才重试；快速重复点击不会并发发送两次。
- [ ] 在 420 × 560、360 × 440、暗色模式和高缩放下确认框不越出窗口、不被滚动区或底栏裁切；触屏环境显示底部操作条。

## 持久化

- [ ] 收藏、历史、兴趣、主题和通用设置在重启后保留。
- [ ] 在兴趣设置拖动列表把手后保存并重启，顺序保持；越靠上的已选兴趣显示越高的生成权重。
- [ ] 历史最多 500 条。
- [ ] 最近浏览每条都有删除按钮，删除后收藏、历史和主界面都不再出现该卡。
- [ ] 最近浏览单卡删除和“清除阅读记录”都必须先确认；取消、Escape 和点击遮罩不会删除，确认后才执行。
- [ ] 通用设置的“清除阅读记录”“清除偏好”“清除全部本地数据”分别显示准确影响；确认前数据不变，清除历史后收藏仍存在。
- [ ] 清除偏好后自定义兴趣消失，内置兴趣的选择、启停和顺序保留，重新进入兴趣设置不会恢复已删项目。
- [ ] 清除全部后回到首次使用状态，阅读历史保持为空，开机启动关闭、快捷键恢复默认且窗口取消置顶。
- [ ] 模型请求、设置保存或桌面后台状态写入进行中时，清除操作会明确要求稍后重试；清除执行中，托盘暂停、窗口状态保存和退出不会把旧数据写回或中断清除。
- [ ] 内容有误后卡片立即隐藏，重启后不再出现。

## 窗口、托盘与快捷键

- [ ] 关闭主窗口后进程留在托盘，第一次明确提示。
- [ ] 托盘左键显示/隐藏；菜单的下一条、暂停、设置和退出有效。
- [ ] 默认 Alt + Shift + Y 显示/隐藏。
- [ ] “鼠标移出后自动收起”默认关闭；开启并保存后，鼠标先进入窗口、再持续移出约 0.7 秒会收至托盘，进程不退出。
- [ ] 快速移出后在 0.7 秒内返回、沿窗口边缘或标题栏移动不会收起；托盘或快捷键恢复后，鼠标尚未重新进入窗口时不会立即消失。
- [ ] 确认弹窗、主菜单、选词查询框、原生下拉控件和文件选择器打开时不会自动收起；拖选文字、兴趣排序、拖动标题栏和调整窗口尺寸期间也不会触发。
- [ ] AI 生成或追问过程中移出会正常收起；重新打开后请求继续且结果完整。
- [ ] 100%、150%、200% 缩放以及主副屏、负坐标显示器下边界判断一致；移到外接显示器后仍按当前窗口外框触发。
- [ ] 第一次自动收起只提示一次恢复方式；关闭开关后不再触发，清除全部本地数据后开关恢复关闭。
- [ ] 快捷键冲突时保存失败并显示中文提示，旧快捷键仍可用。
- [ ] 置顶默认关闭，开启后重启保留。
- [ ] 窗口位置、尺寸和显示器重启后恢复。
- [ ] 拔掉外接显示器后窗口回到当前可见屏幕。

## 提醒

- [ ] 默认仅手动打开，不自动请求通知。
- [ ] 工作日 1 次/2 次按设定时间提醒，不播放声音、不展开窗口。
- [ ] 静默时段、暂停 30 分钟和今天暂停有效。
- [ ] 其他应用全屏时不提醒。
- [ ] 同一分钟的提醒不重复。

## 模型与安全

- [ ] 在通用设置把每日生成总数改为自定义数值（例如 37）并保存；下方立即显示“已生成数/37”，重启后数值保留。
- [ ] 成功生成知识点后重新进入通用设置，“已生成数/总数”的已生成数增加；格式错误、请求失败或重复内容不增加该数字。
- [ ] 将总数调低到不大于今天已生成数后，继续生成会提示达到今天上限，本地知识点仍可浏览。
- [ ] 聚焦“每日生成总数”数字框后滚动鼠标滚轮，数值不发生变化。
- [ ] 使用独立低额度测试账户在设置页输入真实 Key；不要记录或截图完整 Key。
- [ ] 保存后输入框清空，只显示最后四位。
- [ ] 连接测试通过后，随机领域、同领域和指定领域生成可用；不操作时不会后台自动生成。
- [ ] 无效 Key、余额不足、429、超时分别显示可执行中文提示。
- [ ] DeepSeek/Kimi 各生成一批，全部标记“AI 生成 · 未经外部核验”。
- [ ] 删除配置后 Windows Credential Manager 中对应项消失。
- [ ] 删除 API Key 前显示供应商、服务通道和尾号；取消不删除，确认后该通道的凭据及保存的模型/验证状态消失。
- [ ] 已有 API Key 时输入新 Key 会要求覆盖确认；取消保留输入草稿，确认后才替换。模型请求进行中不能清除数据、删除或覆盖凭据。
- [ ] 确认框打开后默认焦点在“取消”，Tab 不离开弹窗；Escape 只关闭弹窗并把焦点还给原按钮。执行中按钮禁用，Escape 与重复点击均无效。
- [ ] 抓包确认请求只访问官方白名单且没有跨域重定向。
